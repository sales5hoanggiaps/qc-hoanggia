# AMIS Sync Worker Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stand up `apps/worker`, a service that authenticates against the real MISA AMIS Open API, pulls 2026 sale orders, and upserts `Product`/`ProductVersion`/`ProductCustomer` rows into the QC database — populating the app with real mã hàng for the first time, without ever overwriting QC content a Manager/Admin has already entered.

**Architecture:** A small standalone Node service (`apps/worker`) sharing `packages/db` with `apps/web`. It exposes a cron job (nightly) and a tiny internal HTTP server (`POST /sync`) that `apps/web`'s "Đồng bộ ngay" button calls. Version detection uses a regex validated against 1000 real AMIS product codes (see spec §6) — not a guess.

**Tech Stack:** TypeScript 5.6, Node >=20, `node-cron` for scheduling, native `fetch` for the AMIS API (no HTTP client dependency needed), Prisma via `@qc/db`, Vitest.

**Spec:** [docs/superpowers/specs/2026-09-09-qc-hoanggia-design.md](../specs/2026-09-09-qc-hoanggia-design.md) §6 (đồng bộ), §12 (rủi ro — both AMIS-related risks there are now resolved with real data)

## Global Constraints

- App QC **không bao giờ** tạo mã hàng/phiên bản qua UI/API tự viết — mọi `Product`/`ProductVersion` chỉ được tạo bởi chính sync worker này, phản ánh những gì đã tồn tại trên AMIS (spec §1, §3).
- Đồng bộ **không lọc theo nhân viên/phòng ban** — khác hẳn `hoanggia-crm`'s `managedCodes` filter. Lấy toàn bộ đơn hàng năm 2026 của cả công ty (spec §12).
- Sync **không bao giờ ghi đè nội dung QC** (TCSP/QC/Đóng gói/Giấy tờ) mà Manager/Admin đã nhập — chỉ tạo mới, hoặc kế thừa+tạo phiên bản mới, hoặc gắn cờ để người dùng tự quyết định (spec §6 bước 5).
- Nhận diện phiên bản dùng regex `^([A-Z]{1,4}\d{4,7})\.(\d{1,2})$` **cộng với** điều kiện `baseCode` đã tồn tại trong hệ thống — cả hai điều kiện đều bắt buộc (spec §6).
- `Category` **không** được sync gán tự động (field `product_category` của AMIS là phân loại dây chuyền sản xuất, không phải taxonomy của app QC) — `Product.categoryId` luôn để `null` khi mới tạo, Manager/Admin tự gán tay.
- `AMIS_APP_ID`/`AMIS_CLIENT_SECRET`/`AMIS_BASE_URL` đã có sẵn trong `infra/.env` (không commit).
- Node >= 20.
- Giao diện tiếng Việt.

- [ ] **Step 8: Write `apps/worker/src/amis/client.ts`**

```ts
import { AmisListResponse } from "./types";

const BASE_URL = process.env.AMIS_BASE_URL || "https://crmconnect.misa.vn";

let cachedToken: string | null = null;

export function __resetTokenCache() {
  cachedToken = null;
}

export async function getAmisToken(): Promise<string> {
  if (cachedToken) return cachedToken;

  const appId = process.env.AMIS_APP_ID;
  const clientSecret = process.env.AMIS_CLIENT_SECRET;
  if (!appId || !clientSecret) {
    throw new Error("Thiếu AMIS_APP_ID/AMIS_CLIENT_SECRET trong biến môi trường của worker");
  }

  const res = await fetch(`${BASE_URL}/api/v2/Account`, {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({ client_id: appId, client_secret: clientSecret }),
  });
  const json = (await res.json()) as { success: boolean; data?: string; user_msg?: string };
  if (!res.ok || !json.success || !json.data) {
    throw new Error(json.user_msg || "Không lấy được token AMIS — kiểm tra lại AppID/mã bảo mật");
  }
  cachedToken = json.data;
  return cachedToken;
}

/** Gọi lại 1 lần với token mới nếu gặp 401 (token hết hạn/bị thu hồi). */
async function authedFetch(path: string): Promise<Response> {
  const appId = process.env.AMIS_APP_ID!;
  const token = await getAmisToken();
  const res = await fetch(`${BASE_URL}${path}`, {
    headers: { Authorization: `Bearer ${token}`, Clientid: appId },
  });
  if (res.status === 401) {
    __resetTokenCache();
    const freshToken = await getAmisToken();
    return fetch(`${BASE_URL}${path}`, {
      headers: { Authorization: `Bearer ${freshToken}`, Clientid: appId },
    });
  }
  return res;
}

/** Phân trang tới khi 1 trang trả về ít hơn pageSize hoặc rỗng. Giới hạn an toàn 500 trang. */
export async function fetchAllPages<T>(basePath: string, pageSize = 100): Promise<T[]> {
  const rows: T[] = [];
  const separator = basePath.includes("?") ? "&" : "?";
  for (let page = 0; page < 500; page++) {
    const res = await authedFetch(`${basePath}${separator}page=${page}&pageSize=${pageSize}`);
    const json = (await res.json()) as AmisListResponse<T>;
    if (!res.ok || !json.success) {
      throw new Error(json.error_message || `Gọi AMIS thất bại tại ${basePath} (HTTP ${res.status})`);
    }
    const data = json.data ?? [];
    rows.push(...data);
    if (data.length < pageSize) break;
  }
  return rows;
}
```

```ts
/**
 * Mẫu regex đã kiểm chứng khớp 100% trên 1000 mã hàng thật lấy từ AMIS
 * (2026-09-09, xem spec §6). Phần trước dấu chấm bắt buộc 4-7 chữ số để
 * loại trừ kiểu đánh số nội bộ khác của AMIS (vd "AA03.000170" — chỉ 2
 * chữ số trước dấu chấm, số sau dấu chấm dài và có số 0 ở đầu).
 */
const VERSION_SUFFIX_RE = /^([A-Z]{1,4}\d{4,7})\.(\d{1,2})$/;

export function parseVersionSuffix(
  code: string
): { baseCode: string; versionNumber: number } | null {
  const match = code.match(VERSION_SUFFIX_RE);
  if (!match) return null;
  return { baseCode: match[1], versionNumber: Number(match[2]) };
}
```

```ts
import { prisma, ProductStatus } from "@qc/db";
import { parseVersionSuffix } from "./version-detection";

export interface UpsertProductInput {
  amisProductId: string;
  code: string;
  name: string;
  description: string | null;
}

export type UpsertResult = { kind: "created" | "new_version" | "linked_existing" };

/** Sao chép nội dung 4 mục từ 1 ProductVersion sang 1 ProductVersion mới (cùng dữ liệu, khoá ngoại mới). */
async function cloneVersionContent(fromVersionId: string, toVersionId: string) {
  const [tcsp, qc, packaging, documents] = await Promise.all([
    prisma.tCSPData.findUnique({ where: { versionId: fromVersionId }, include: { specRows: true, media: true } }),
    prisma.qCData.findUnique({ where: { versionId: fromVersionId }, include: { media: true } }),
    prisma.packagingData.findUnique({ where: { versionId: fromVersionId }, include: { media: true } }),
    prisma.documentsData.findUnique({ where: { versionId: fromVersionId }, include: { files: true } }),
  ]);

  if (tcsp) {
    const newTcsp = await prisma.tCSPData.create({
      data: {
        versionId: toVersionId,
        materialCode: tcsp.materialCode,
        description: tcsp.description,
        preparedBy: tcsp.preparedBy,
        approvedBy: tcsp.approvedBy,
        approvedAt: tcsp.approvedAt,
      },
    });
    for (const row of tcsp.specRows) {
      await prisma.tCSPSpecRow.create({
        data: {
          tcspId: newTcsp.id,
          groupName: row.groupName,
          criterion: row.criterion,
          value: row.value,
          tolerance: row.tolerance,
          unit: row.unit,
          note: row.note,
          sortOrder: row.sortOrder,
        },
      });
    }
    for (const media of tcsp.media) {
      await prisma.mediaAsset.create({
        data: { storageKey: media.storageKey, mimeType: media.mimeType, caption: media.caption, sortOrder: media.sortOrder, tcspId: newTcsp.id },
      });
    }
  }

  if (qc) {
    const newQc = await prisma.qCData.create({
      data: { versionId: toVersionId, checklist: qc.checklist, knownDefects: qc.knownDefects, specialNotes: qc.specialNotes },
    });
    for (const media of qc.media) {
      await prisma.mediaAsset.create({
        data: { storageKey: media.storageKey, mimeType: media.mimeType, caption: media.caption, sortOrder: media.sortOrder, qcId: newQc.id },
      });
    }
  }

  if (packaging) {
    const newPackaging = await prisma.packagingData.create({
      data: { versionId: toVersionId, instructions: packaging.instructions, specialNotes: packaging.specialNotes },
    });
    for (const media of packaging.media) {
      await prisma.mediaAsset.create({
        data: { storageKey: media.storageKey, mimeType: media.mimeType, caption: media.caption, sortOrder: media.sortOrder, packagingId: newPackaging.id },
      });
    }
  }

  if (documents) {
    const newDocuments = await prisma.documentsData.create({ data: { versionId: toVersionId } });
    for (const file of documents.files) {
      await prisma.productDocument.create({
        data: { documentsId: newDocuments.id, kind: file.kind, label: file.label, storageKey: file.storageKey },
      });
    }
  }
}

export async function upsertProductFromAmis(input: UpsertProductInput): Promise<UpsertResult> {
  const existingByAmisId = await prisma.product.findUnique({ where: { amisProductId: input.amisProductId } });
  if (existingByAmisId) {
    return { kind: "linked_existing" };
  }

  const parsed = parseVersionSuffix(input.code);
  const existingBase = parsed ? await prisma.product.findUnique({
    where: { baseCode: parsed.baseCode },
    include: { currentVersion: true },
  }) : null;

  if (parsed && existingBase && existingBase.currentVersion) {
    // Phiên bản mới của mã đã tồn tại — kế thừa nội dung, tạo bản ghi mới, không đụng bản cũ.
    const newVersion = await prisma.productVersion.create({
      data: {
        productId: existingBase.id,
        versionNumber: existingBase.currentVersion.versionNumber + 1,
        amisProductId: input.amisProductId,
        name: input.name,
        description: input.description,
        isCurrent: true,
        createdByAmisSync: true,
      },
    });
    await cloneVersionContent(existingBase.currentVersion.id, newVersion.id);
    await prisma.productVersion.update({ where: { id: existingBase.currentVersion.id }, data: { isCurrent: false } });
    await prisma.product.update({ where: { id: existingBase.id }, data: { currentVersionId: newVersion.id } });
    await prisma.changeLogEntry.create({
      data: {
        versionId: newVersion.id,
        fieldPath: "version",
        oldValue: String(existingBase.currentVersion.versionNumber),
        newValue: String(newVersion.versionNumber),
        source: "AMIS_SYNC",
      },
    });
    return { kind: "new_version" };
  }

  // Mã hoàn toàn mới (không khớp mẫu phiên bản, hoặc baseCode chưa từng thấy).
  const baseCode = parsed ? parsed.baseCode : input.code;
  const product = await prisma.product.create({
    data: {
      baseCode,
      amisProductId: input.amisProductId,
      status: ProductStatus.PENDING_QC,
    },
  });
  const version = await prisma.productVersion.create({
    data: {
      productId: product.id,
      versionNumber: 1,
      amisProductId: input.amisProductId,
      name: input.name,
      description: input.description,
      isCurrent: true,
      createdByAmisSync: true,
    },
  });
  await prisma.product.update({ where: { id: product.id }, data: { currentVersionId: version.id } });
  return { kind: "created" };
}
```

```ts
import { prisma } from "@qc/db";
import { fetchAllPages } from "../amis/client";
import { AmisSaleOrder, AmisCustomer } from "../amis/types";
import { upsertProductFromAmis } from "./upsert-product";
import { logger } from "../logger";

export interface RunSyncResult {
  newProducts: number;
  newVersions: number;
  updatedLinks: number;
  syncLogId: string;
}

const YEAR_START = new Date("2026-01-01T00:00:00.000+07:00");
const YEAR_END = new Date("2027-01-01T00:00:00.000+07:00");

export async function runAmisSync(): Promise<RunSyncResult> {
  const syncLog = await prisma.syncLog.create({ data: {} });
  let newProducts = 0;
  let newVersions = 0;
  let updatedLinks = 0;
  let flaggedReview = 0;

  try {
    const [orders, customers] = await Promise.all([
      fetchAllPages<AmisSaleOrder>("/api/v2/SaleOrders?orderBy=modified_date&isDescending=true"),
      fetchAllPages<AmisCustomer>("/api/v2/Customers"),
    ]);

    const ordersIn2026 = orders.filter((o) => {
      if (!o.sale_order_date) return false;
      const d = new Date(o.sale_order_date);
      return d >= YEAR_START && d < YEAR_END;
    });

    const customerByName = new Map(customers.map((c) => [c.account_name, c]));

    for (const order of ordersIn2026) {
      let customerId: string | null = null;
      if (order.account_name) {
        const amisCustomer = customerByName.get(order.account_name);
        const amisCustomerId = amisCustomer ? String(amisCustomer.id) : `name:${order.account_name}`;
        const customer = await prisma.customer.upsert({
          where: { amisCustomerId },
          update: { name: order.account_name },
          create: { amisCustomerId, name: order.account_name },
        });
        customerId = customer.id;
      }

      for (const mapping of order.sale_order_product_mappings ?? []) {
        if (!mapping.product_code) continue;
        const amisProductId = `code:${mapping.product_code}`; // xem "Cannot verify" note trong report Task 4

        const existing = await prisma.product.findUnique({ where: { amisProductId } });
        const result = await upsertProductFromAmis({
          amisProductId,
          code: mapping.product_code,
          name: mapping.description || mapping.product_code,
          description: mapping.description,
        });
        if (result.kind === "created") newProducts++;
        if (result.kind === "new_version") newVersions++;

        if (customerId) {
          const product = await prisma.product.findUnique({ where: { amisProductId } });
          if (product) {
            await prisma.productCustomer.upsert({
              where: { productId_customerId: { productId: product.id, customerId } },
              update: { lastOrderDate: order.sale_order_date ? new Date(order.sale_order_date) : null },
              create: {
                productId: product.id,
                customerId,
                lastOrderDate: order.sale_order_date ? new Date(order.sale_order_date) : null,
              },
            });
            updatedLinks++;
          }
        }

        if (existing && result.kind === "linked_existing" && existing.status !== "PENDING_QC") {
          // Mã đã có nội dung QC, không có phiên bản mới, nhưng tên/mô tả từ đơn hàng gần nhất
          // khác dữ liệu đang lưu — gắn cờ chứ không tự sửa (spec §6 bước 5).
          const currentVersion = await prisma.productVersion.findUnique({
            where: { id: existing.currentVersionId ?? "" },
          });
          if (currentVersion && currentVersion.name !== (mapping.description || mapping.product_code)) {
            flaggedReview++;
          }
        }
      }
    }

    await prisma.syncLog.update({
      where: { id: syncLog.id },
      data: { finishedAt: new Date(), newProducts, updatedLinks, newVersions, flaggedReview },
    });
    logger.info(
      `Đồng bộ AMIS xong: ${newProducts} mã mới, ${newVersions} phiên bản mới, ${updatedLinks} liên kết khách hàng, ${flaggedReview} mã cần xem xét.`
    );
  } catch (err) {
    const message = err instanceof Error ? err.message : "Lỗi không xác định";
    logger.error("Đồng bộ AMIS thất bại:", message);
    await prisma.syncLog.update({
      where: { id: syncLog.id },
      data: { finishedAt: new Date(), errorMessage: message, newProducts, updatedLinks, newVersions, flaggedReview },
    });
  }

  return { newProducts, newVersions, updatedLinks, syncLogId: syncLog.id };
}
```

```ts
import http from "node:http";
import { runAmisSync } from "./sync/run-sync";
import { logger } from "./logger";

export function createServer(): http.Server {
  return http.createServer(async (req, res) => {
    if (req.method !== "POST" || req.url !== "/sync") {
      res.writeHead(404).end();
      return;
    }

    const token = req.headers["x-internal-token"];
    if (!token || token !== process.env.SYNC_INTERNAL_TOKEN) {
      res.writeHead(401, { "Content-Type": "application/json" }).end(JSON.stringify({ error: "Unauthorized" }));
      return;
    }

    try {
      const result = await runAmisSync();
      res.writeHead(200, { "Content-Type": "application/json" }).end(JSON.stringify(result));
    } catch (err) {
      logger.error("Lỗi xử lý /sync:", err);
      res.writeHead(500, { "Content-Type": "application/json" }).end(JSON.stringify({ error: "Đồng bộ thất bại" }));
    }
  });
}
```

`vitest.config.ts` (Task 1) only loads env vars for *tests*, via Vite's `loadEnv`. The actual worker process (`tsx watch` in dev, or the built `dist/index.js` in Docker) is plain Node — nothing loads `infra/.env` for it automatically, the same gap the Foundation plan's vitest fix (I4) solved only for `apps/web`'s test runner, not for any real running process. Fix it here with a small dependency-free loader, imported first, before anything else reads `process.env`:

```ts
import fs from "node:fs";
import path from "node:path";

// apps/worker/src(or dist)/env.ts -> repo root is 3 levels up either way
// (apps/worker/src/env.ts or apps/worker/dist/env.js are both 3 levels deep).
const envPath = path.resolve(__dirname, "../../../infra/.env");

if (fs.existsSync(envPath)) {
  const content = fs.readFileSync(envPath, "utf8");
  for (const line of content.split("\n")) {
    const match = line.match(/^([A-Z_][A-Z0-9_]*)=(.*)$/);
    if (match && !(match[1] in process.env)) {
      process.env[match[1]] = match[2];
    }
  }
}
```

```ts
import { NextResponse } from "next/server";
import { UserRole } from "@qc/db";
import { auth } from "@/lib/auth";
import { assertRole, ForbiddenError } from "@/lib/auth/guard";

const MANAGER_OR_ADMIN = [UserRole.MANAGER, UserRole.ADMIN];

export async function POST() {
  const session = await auth();
  try {
    assertRole(session?.user.role, MANAGER_OR_ADMIN);
  } catch (err) {
    if (err instanceof ForbiddenError) return NextResponse.json({ error: err.message }, { status: 403 });
    throw err;
  }

  const workerUrl = process.env.SYNC_WORKER_URL;
  const token = process.env.SYNC_INTERNAL_TOKEN;
  if (!workerUrl || !token) {
    return NextResponse.json({ error: "Chưa cấu hình SYNC_WORKER_URL/SYNC_INTERNAL_TOKEN" }, { status: 500 });
  }

  const res = await fetch(`${workerUrl}/sync`, {
    method: "POST",
    headers: { "x-internal-token": token },
  });
  const body = await res.json();
  return NextResponse.json(body, { status: res.status });
}
```

```tsx
"use client";

import { useState } from "react";

export function SyncPanel({ initialLogs }: { initialLogs: SyncLogRow[] }) {
  const [logs, setLogs] = useState(initialLogs);
  const [syncing, setSyncing] = useState(false);
  const [error, setError] = useState<string | null>(null);

  async function handleSync() {
    setSyncing(true);
    setError(null);
    const res = await fetch("/api/admin/sync", { method: "POST" });
    setSyncing(false);
    if (!res.ok) {
      setError("Đồng bộ thất bại — xem log bên dưới sau khi tải lại trang.");
      return;
    }
    window.location.reload();
  }

  return (
    <div className="space-y-6 p-6">
      <h1 className="text-lg font-semibold">Đồng bộ AMIS</h1>
      <button
        onClick={handleSync}
        disabled={syncing}
        className="rounded bg-brand-600 px-4 py-1.5 text-white hover:bg-brand-700 disabled:opacity-50"
      >
        {syncing ? "Đang đồng bộ..." : "Đồng bộ ngay"}
      </button>
      {error && <p className="text-sm text-red-600">{error}</p>}

      <table className="w-full border-collapse text-sm">
        <thead>
          <tr className="border-b text-left">
            <th className="p-2">Bắt đầu</th>
            <th className="p-2">Mã mới</th>
            <th className="p-2">Phiên bản mới</th>
            <th className="p-2">Liên kết KH</th>
            <th className="p-2">Lỗi</th>
          </tr>
        </thead>
        <tbody>
          {logs.map((log) => (
            <tr key={log.id} className="border-b">
              <td className="p-2">{new Date(log.startedAt).toLocaleString("vi-VN")}</td>
              <td className="p-2">{log.newProducts}</td>
              <td className="p-2">{log.newVersions}</td>
              <td className="p-2">{log.updatedLinks}</td>
              <td className="p-2 text-red-600">{log.errorMessage || ""}</td>
            </tr>
          ))}
        </tbody>
      </table>
    </div>
  );
}

interface SyncLogRow {
```
